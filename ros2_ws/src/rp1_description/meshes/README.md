# Generated meshes -- do not hand-edit

`chassis.stl`, `wheel_front_left.stl`, `wheel_front_right.stl`, `wheel_rear_left.stl`,
`wheel_rear_right.stl` are exported from the `rp1-mechanical` submodule's FreeCAD
assembly by `rp1-mechanical/tools/export_urdf_meshes.py`. Re-run that script (with
FreeCAD's own Python, not system python3) whenever the CAD model changes, and commit the
regenerated STLs alongside any resulting `urdf/rp1_drive.urdf` origin updates.
